Social Security card

In short. How refugees get a Social Security number and card.

On this page
  • If you asked for an SSN during processing
  • If you apply at an SSA office
  • Lost card or stolen number

If you asked for an SSN during processing

When a Social Security number is requested in the immigration process, DHS sends the data to SSA. SSA assigns the number and mails the card to the address you gave, or to your sponsoring agency if you had no address. The same rule says the card is sent within a reasonable time after the number is assigned. It does not give a number of days. That rule is 20 CFR 422.103, in the Code of Federal Regulations [source, source].

If you apply at an SSA office

Staff follow the Program Operations Manual System (POMS) [source].

  • SSA treats refugees as having permanent work authorisation and issues an unrestricted card (no legend) [source].
  • One document can prove age, identity and status, for example the I-94 website printout with the State Department transportation boarding letter carrying the refugee admission stamp [source].
  • An I-94 with the refugee admission stamp, or an EAD with category A3, is also accepted [source].

Lost card or stolen number

Replacement and identity theft options are on SSA's Social Security number page [source].

A number of days for the card to arrive: not stated. The regulation says only that the card is sent within a reasonable time.
